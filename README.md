# Rahul Singh — Full Stack & Mobile Developer Portfolio

A high-performance, responsive portfolio showcasing full-stack web and mobile application engineering. Built with React, Vite, Framer Motion, and pure modern CSS.

---

## ✨ Features

- **Dynamic 4-Theme System**:
  - 🌊 **Ocean Blue**: Deep ocean theme with marine visuals & interactive cursor ripple.
  - 🕉️ **Karma Coder**: Warm spiritual aesthetic with vibrant ambient energy.
  - 🤖 **Robotic**: Cyber-mech interface with circuit elements & futuristic styling.
  - 🍃 **Emerald Classic**: Lush, minimalist modern aesthetic.
- **Water Drop Hover Effects**: Apple iOS-grade fluid dewdrop tooltips with spring physics and optical blur.
- **3D Foldable Paper Badge**: Right-to-left origami paper fold & unfold animation revealing *"Let's build together"*.
- **Mobile Fluid Tab Bar**: Bottom liquid glass dock containing a segmented 4-theme switcher with zero horizontal overflow.
- **Resume Integration**: Direct PDF download linked from the Hero CTA and served statically from `/public/Rahul_Singh_Mobiledev.pdf`.
- **Production-Grade SEO & OpenGraph**: Pre-configured meta tags, Twitter card previews, and favicon branding.
- **Deployment-Ready**: Out-of-the-box support for Vercel (`vercel.json`) and Netlify (`public/_redirects`).

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Animations**: Framer Motion, CSS 3D Transforms, Hardware-accelerated GPU transitions
- **Icons**: React Icons (`react-icons/lu`, `react-icons/tb`, `react-icons/fa`)
- **Styling**: Vanilla CSS (Custom Design System, Liquid Glass Refraction, Responsive Media Queries)

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/mrsinghmzp/rahul-portfolio.git
cd rahul-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

---

## 🌐 Deployment

### Vercel
Connect your GitHub repository to [Vercel](https://vercel.com) — it will automatically detect Vite and deploy.

### Netlify
Drag and drop the `dist/` directory onto [Netlify Drop](https://app.netlify.com/drop) or connect this repository.
